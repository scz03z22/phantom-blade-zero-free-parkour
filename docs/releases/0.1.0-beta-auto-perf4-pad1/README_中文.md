# 自由跑酷 / 自动探索测试版

版本：0.1.0-beta-auto-perf4-pad1。安装后自动生效，无需按功能键。

这是用于自由探索的实验性 Mod。地图上有许多可见但没有实体碰撞的表面，使用本 Mod 后可能掉进地形、越出地图或无法返回。Mod 不会为场景补上碰撞。请保留存档备份；需要返回正常区域时可使用已有的穿行符。所有 Lua 源码均包含在安装包中。

## 功能与操作

- 自动启用蹬墙翻身和连续向上蹬墙。朝实体墙跳起，再按一次跳跃键（键盘空格 / 手柄下方面键，Xbox A、PlayStation ×）：第二下短按为单蹬翻身，保持按住为连续上蹬。提前在空中按第二下的预输入、偏侧面接触也保留。连续动作松开跳跃键后结束。键盘与手柄可混用；两个键同时按住时视为同一次按住，全部松开才算松手。
- 连续上蹬调用游戏原有的多次蹬墙动画；顶部或突起处通过前方探测、落脚与通路检查，尝试衔接原有手撑翻越。并非每个屋檐都能通过，过大的突起、不规则表面和缺失碰撞仍可能阻挡动作。横向跑墙暂不启用。
- 自动关闭已识别空气墙对 Pawn 通道的阻挡：样条空气墙 BP_SplineWall，以及隐藏、使用 Profile_LA_InvisibleWall 的引擎基础 Cube。普通可见模型碰撞不会被一并删除，其他类型的空气墙可能仍存在。Pawn 通道也可能影响敌人和 NPC。
- 自动关闭已加载、明确使用 GE_Kill 效果的区域对 Pawn 通道的响应。它不等于免疫全部死亡：其他伤害、掉落规则、脚本死亡与未识别的危险区域不在此功能范围内。
- 穿行符无消耗：拦截 Item_Traversing 的扣除；需要背包原本已有该道具，不会赠送道具，也不会增加其他物品。

环境处理会分批完成。进入存档或传送后请稍等数秒，新加载对象较多时可能更久。没有开关和恢复队列；运行期间不支持热键恢复碰撞，完整退出游戏会撤销本次会话的碰撞修改。

## 安装

1. 完全退出游戏。先安装适配本游戏的 UE4SS 前置。Mod 包不包含 UE4SS，也不替换其共享库。
2. 找到 `游戏目录\platform\steam\ue4ss\Mods\`。
3. 备份并移走已有的 `PBZFreeParkour`、`PBZAutoExplore` 文件夹，再复制本包 `Mods` 下这两个同名文件夹到上述目录。
4. 不要同时启用旧完整版/精简版中的 `PBZNoSplineWall`、`PBZNearbyKillToggle` 或其他同功能脚本。避免同名文件覆盖后残留旧文件，也不要把本包嵌套成 `Mods\Mods`。
5. 启动游戏，进入存档后自动启用。此包不注册 F6/F7/F8/F9 等功能开关。默认支持键盘空格与手柄下方面键（Xbox A / PlayStation ×）。请保留 UE4SS 原有的 `Mods\shared` 文件夹。

正确结构示例：`ue4ss\Mods\PBZFreeParkour\Scripts\main.lua`，同级存在 `PBZFreeParkour\enabled.txt`；`PBZAutoExplore` 也应为同样结构。

版本核对：手柄输入版应额外显示 `pad1_input_loaded; jump=SpaceBar|Gamepad_FaceButton_Bottom`。`ue4ss\UE4SS.log` 中应有 `candidate8_loader=no_postponement_for_invalid_object`；`lite_auto_enabled` 表示自动跑酷已开启。部分内部旧日志仍含 F8 或 lite 字样，不代表此包需要按键启动。

本轮验证环境：游戏构建 302256-17280，UE4SS 3.0.1 Beta（1ceefac8）。其他游戏更新、前置版本、输入方案与其他 Mod 的组合未全部验证。

## 手柄与改键

左摇杆仍使用游戏自己的移动控制。双按跳跃、第二下短按为单蹬翻身；第二下持续按住为连续上蹬。空中提前按第二下、碰墙后衔接的预输入也适用于手柄。长按分界仍为约 0.18 秒。

`Mods\PBZFreeParkour\Scripts\input_bindings.lua` 可分别指定 `keyboard_jump` 与 `gamepad_jump`。这里使用游戏收到的 Unreal 按键名称；默认是 `SpaceBar` 与 `Gamepad_FaceButton_Bottom`。修改后需完整重启游戏，并与游戏或 Steam Input 的跳跃绑定保持一致。模组不会自动读取或修改游戏内的改键设置。比如把游戏手柄跳跃改到右肩键时，可将 `gamepad_jump` 改为 `Gamepad_RightShoulder`；键盘改为 J 时填 `J`。填 `false` 可禁用该输入来源。

需要手柄已被游戏识别；若 Steam Input 把按钮转换为空格，原有键盘通路也可触发。模组本身不增加手柄驱动。下方按键说明以游戏收到的按钮为准。

本次手柄补丁通过 26 项离线检查，包含短按/长按、贴墙双按、空中预输入、混合设备按住/松开、人物更换与换图资源重载模拟。尚未用实体手柄实测，也没有为 pad1 重测实机帧率。补丁只扩展输入读取，不增加循环、世界枚举或碰撞扫描；静置模拟中每个 30 毫秒循环最多增加两次按键查询，同时少构造两次跳跃 FName。下面的实机性能数字来自补丁之前的 perf4 版本。

## 本轮优化

- 减少每次循环重复寻找角色和世界的调用，并在身份变化时重新验证。
- 地面无跳跃请求时减少无用墙面扫描，保留跳跃和空中预输入。
- 重用自有跑酷对象及已验证组件位置，减少连续动作准备时的重复枚举。
- 在需要自行加载上蹬资源时，于人物上方高处放置一个自有上墙体积，关闭其触发盒、隐藏交互提示，使资源保持可用，降低回收后重复加载和查找的停顿。
- 针对加载后暂时查不到有效类而导致连续上蹬停用的时序做了修正，离线复现通过；这不覆盖全部资源加载错误。
- 对持续无法加载的异常状态，自动查找间隔逐步延长至最多 60 秒，减少无效重复查找；正常动作请求仍自行检查所需资源。这是异常情况下的减负措施，收益目前只有离线计数证据。
- 空气墙与 GE_Kill 使用首次处理和新对象事件队列；不反复全图扫描，不维护恢复日志。

这些改动旨在降低脚本开销和特定卡顿。目前的对照没有证明平均帧率提高，也不能保证完全没有卡顿；第一次加载资源、地图流送、复杂跑酷启动仍有成本。

测试机实测（同一站位与镜头，静置 206 秒）：旧版在上蹬资源加载被阻断之后，约每 0.5 秒出现一帧停顿，共 404 帧超过 20 毫秒；本版本为 0，P99 帧时间由 31.61 降为 9.22 毫秒，最慢帧为 17.83 毫秒。旧版与本版本分别在到达后约 2.5 和 2.1 分钟开始采集，各一个独立进程。这个差别只在旧版进入该异常状态之后才存在，不代表一般情况下的平均帧率差异。本版本的普通帧并不比旧版的普通帧更快。

刚到达没有原生上墙点的地图时，首次加载仍有成本：本构建实机记录到一次约 55 毫秒的加载器耗时。上一构建到达后曾重复出现九次约 34–50 毫秒的耗时；移除重复等待分支后，本轮没有再观察到该重复现象。上述 206 秒静置采样在首次加载之后开始，没有把它算进最慢帧，初次加载卡顿尚未消除。

存档：测试中以只读方式查询了游戏的存档登记。模组生成的上墙体积会被游戏的关卡对象管理器登记；在该体积被使用过、并在存档点存档之后，查询显示没有为它保存数据，已载入的存档数据中也没有这类运行时对象的条目。这只是一次会话、一张地图的观察，不能保证对存档完全没有影响，请保留存档备份。另做过一次原版回读：把本模组实际使用后生成的测试存档交给不加载 UE4SS 的原版游戏读取，文件哈希相符，能正常进入并站在场景中。这只是一次冒烟检查，不保证所有存档都不受影响。

刚换地图、资源尚未就绪时，第一次蹬墙可能不触发，落地稍等后可再次尝试。运行错误可能使跑酷自动停用；脚本包含换图或人物身份变化后的有限恢复（每次启动最多三次，异常恢复规则仅离线验证）。若仍不恢复，请完整重启游戏。请勿据此认为模组对存档绝无影响。

## 卸载与回退

完全退出游戏后，移走 `PBZFreeParkour` 和 `PBZAutoExplore` 两个文件夹，或移走各自的 `enabled.txt`。重新启动后，此 Mod 的运行时碰撞修改不再保留。恢复旧版时，应还原备份的完整文件夹，不要同时启用两个版本。

反馈时请附上游戏版本、前置版本、具体地点、触发方式及是否刚传送，最好带短录像和 UE4SS 日志。场景补碰撞、复杂表面上的连续蹬墙仍需后续完善。
