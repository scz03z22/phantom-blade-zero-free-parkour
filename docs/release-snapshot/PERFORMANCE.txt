性能优化候选 — 2026-11-12 / 0.1.0-beta-perf1

已安装到本机，另存为候选 ZIP；未上传 Nexus/GitHub，也未覆盖先前发布 ZIP。

本轮修改
1. F8：站稳、无方向/空格输入两秒后暂停重复墙面扫描；输入、移动或空中状态仍执行扫描，不返回旧命中。不改变动作、墙面阈值和预输入规则。
2. F8：原版互动已阻止加载时，提前跳过资源类查找和能力遍历；真正加载仍执行原先完整检查。不跨帧缓存 UObject。
3. F7：待处理区域分批推进，逐个写入/恢复；失败时退避。启用期间重扫改为约十秒，开关时立即请求处理，但安全条件仍可延后。写入使用精确路径解析，再核对对象地址、世界、类型、效果、组件归属、边界和碰撞响应，避免每次写入前后反复遍历全部区域。
4. F9：隐藏立方体批处理加入约三毫秒 CPU 预算，每轮仍最多 64 个对象，至少处理一个对象；单个原生调用无法被中途打断。恢复账本和冲突检查不变。
5. F6：一次同步收集内复用已校验玩家/世界引用，逐对象验证仍保留，收集前后重新获取并确认身份；减少重复的全局 PlayerController 查找。不缓存到下次刷新、不改变区域几何。

实机帧时间（PresentMon；同存档点固定镜头、OBS 关闭、未修改画质）
数据是 Present 间隔，不能直接等同于每个画面的渲染时间或主观流畅度。

平均帧率受场景动画、光照、运行状态影响；主要证据是特定周期性长帧在对照中消失，并非保证提升固定百分比帧率。

验证及限制
六组离线回归通过：F7 分批/恢复/对象替换与失败、F8 静止/输入/下降/预输入、资源加载安全检查及早退、F9预算/440对象恢复/流式加载/冲突、F6几何与扫描中玩家/世界替换。
当前场景加载16个目标类型区域，但30米内选中0个。当前实机测试没有覆盖F7新适配器对附近区域的实际写入，也没有覆盖F6大量红绿线框的绘制负载；已有用户验证是此前版本，不能替代本轮复测。
F9本轮实际恢复381个样条组件和15个隐藏立方体，日志errors=0、conflicts=0。F6、F7、F8、F9最终均关闭；没有继续录屏。
本轮未验证连续动作中帧率、所有地点、长时间跑图、死亡/换图、键位重映射。没有修复既有少数地点上升过高等动作问题。未承诺“完全不卡顿”。

English
This is a local performance candidate, not an uploaded replacement for the previous release.
Changes reduce idle wall queries, reject prohibited asset-load attempts before expensive lookups, batch F7 writes/restoration with guarded exact-object resolution, add a ~3ms per-step CPU budget to F9 hidden-cube batches, and remove repeated controller enumeration inside each synchronous F6 geometry collection. Original safety and identity checks remain. F7 enabled rescans now run about every ten seconds; writes/restoration may still be deferred.
Stationary PresentMon comparisons at the same save point, OBS off, unchanged graphics settings:
- F8 before/after: 45 versus 0 intervals above 50ms per 30s; P99 55.80 versus 30.49ms.
- All four enabled, before/after F6 fix: 9 versus 0 intervals above 50ms per 45s; max 131.00 versus 29.03ms.
- Final all-off: 83.81 average FPS, max27.48ms, no interval above50ms in30s.
These are present intervals and short stationary comparisons, not a universal FPS guarantee. Six mocked regression suites passed. No eligible kill volume was within30m at this test position, so actual nearby F7 mutations and dense F6 rendering require live regression. F9 restoration logged381 spline components and15 cubes without reported errors/conflicts. Active-movement, long-session, reload/map-transition and live key-rebinding testing remain incomplete. All four features were left off after testing.
