PBZ Free Parkour — 影之刃零自由跑酷
性能候选版 / 0.1.0-beta-perf1 / 2026-11-12（未上传）

【默认按键】
F6：显示／隐藏附近约 30 米内已识别 GE_Kill 区域的碰撞线框，约每 5 秒刷新；不是所有模型碰撞。红色表示 Pawn 响应仍存在，绿色表示响应忽略或碰撞关闭。
F8：开启／关闭自由跑酷，开启时播放铃铛声。
F9：开启／关闭去空气墙效果，再按一次恢复本模组修改的阻挡。
F7：开启／关闭附近指定即死区域的禁用效果，再按一次请求恢复。
空格：第一次跳跃；第二次短按尝试单蹬上翻，第二次持续按住尝试连续向上蹬墙。
四个功能独立开关，每次启动游戏均默认关闭；开启后持续生效，不限一次。
F6/F8/F7/F9 可以分别改键，方法见后文。动作输入目前仍固定使用空格。

F7/F8/F9 开启时播放铃声，恢复／关闭完成时播放卖出声；F6 不播放开关音效。

【测试版与探索风险——请先阅读】
这是测试版 mod，不代表游戏已经获得完整、可靠的自由探索支持。
在我们的越界测试中，游戏中存在大量看得见场景表面、但缺少相应有效碰撞的位置；玩家常把它们称为“只有贴图没有碰撞”。这不一定表示没有三维模型，而是可见表面不能提供正常阻挡或落脚。
开启本模组的跑酷、去空气墙或关闭即死区域功能后，尤其越过原版边界时，极易穿入模型、卡住、掉出地图或影响任务流程。本模组不会自动补齐这些场景碰撞，关闭即死区域也不等于无敌。
如果想要完整的自由活动体验，后续需要大家群策群力，定位缺失或不合理的场景碰撞，尝试补碰撞或添加更贴合表面的边界。欢迎提供地点、录像、游戏版本及技术建议；目前没有可靠的全地图自动修补方案。
请备份存档。恢复空气墙和即死区域前，先回到正常、安全的实体地面。

【已实装的两种跑酷动作】
1. 单蹬上翻
开启 F8 后，在可阻挡角色的实体墙附近先跳跃，再短按第二次空格。支持贴墙快速双空格、按住前进顶墙双空格，以及空中提前按第二次空格、之后接触墙面的预输入。对侧向接触有一定容错，但不代表任意朝向和表面均可触发。
第二次按键在约 0.18 秒内松开走短动作分支。调用原版低墙跑动起手的上墙动作 Hun_Wall_Run_Up_Low_RunStart_Montage，表现为蹬一下后翻转上升；没有导入新的角色动画。
动作使用原版特殊移动能力，脚本尝试在顶点解除额外滞空并恢复下落；不能保证每次都站上平台。

2. 连续向上蹬墙
同样先跳跃、再按第二次空格，并将第二下持续按住约 0.18 秒以上。检测到合适的实体墙接触且原版能力可用后，进入连续上蹬。
复用原版 BP_ASM_UpRunning / GA_ASM_UpRunning 动作流程：Hun_Unarmed_WallRun_Start_Montage 起手、Hun_Unarmed_WallRun_Loop_Montage 连蹬，原版收尾可进入 Hun_Unarmed_CloudStep_End_Montage；退出时也可能播放 Hun_Unarmed_WallRun_JumpOut_Forward_Montage，取决于原版状态。
持续按住空格继续尝试上升。松手、失去支撑、头顶阻挡、长时间不能上升、关闭模式等会发起结束；已进入正常收尾时尽量让收尾完整播放。单次连蹬有约 10 秒保护时限，不是无限爬升。
每次动作完成并落稳后建议等约 4 秒再试。原版交互或其他特殊动作正在执行时，可能拒绝启动。两种动作都依赖实际碰撞检测，不根据画面贴图判定；未提供全程脚部贴墙 IK。

【连蹬后越过房檐、横梁等凸起的处理】
当前改动的核心是“测量实际墙顶和落点，再调整原版动作终点”。启动连蹬时，在墙体后方多个距离采样碰撞，结合角色允许站立的坡度与相邻支撑，选取可用高度和前后距离，修正原版上蹬的结束位置，让原版翻身收尾尝试越过边沿。
还保留小腿前方的无阻挡查询：探测前端为空或被实体挡住时，在上蹬结束、落脚和路径检查通过后，可尝试交给角色原版手撑翻越组件。它只是辅助衔接，不保证一定播放翻越。
如果测不到可信的墙顶，仍允许有限度地上蹬，但会在虚拟终点的收尾窗口之前提前退出，避免把虚构高度当成真实平台。未额外添加收尾向上的冲量。
部分地点已改善；宽房檐、复杂凸起、缺失碰撞仍可能失败或落回。少数位置还有过度上升／“飞天”残留，只减轻了程度，没有彻底解决。不能理解为已经实现“任何房梁都能翻越”或碰到凸起必定空翻。

【F9 实际取消哪些空气墙】
A. BP_SplineWall_C 的 DynamicMeshComponent：仅将对 Pawn 通道的阻挡改为忽略。
B. 满足全部条件的 StaticMeshActor：使用 /Engine/BasicShapes/Cube.Cube，Actor 或组件在游戏中隐藏，碰撞配置为 Profile_LA_InvisibleWall。用于处理此前发现的透明立方体阻挡／支撑。
引擎可能在修改响应后把配置名变成 Custom；本版只对本次会话已经核实、对象身份仍匹配的上述立方体继续处理，不会因此把任意 Custom 模型都禁用。
不删除物体，不修改其他碰撞通道。效果针对已加载的目标对象，约每 3 秒启动检查，并分批处理；并非仅限角色附近 30 米。流式加载后可能短暂延迟。
再次按 F9 恢复本模组记录的 Pawn 响应，分批恢复期间需要等待。不会把完整碰撞配置名强行改回，以免覆盖其他通道设置。
这不是全空气墙移除器。其他隐藏形状、未识别的阻挡体、模型自带的粗略碰撞可能仍然存在。正常可见模型不会仅因为阻挡角色就被整体禁用，但越过被移除的边界后，仍可能进入缺少碰撞的区域。

【F7 即死区域开关】
只处理角色附近约 30 米内、明确使用 GE_Kill 的指定区域，启用时立即请求扫描，启用期间约每 10 秒重扫。每次处理一个区域，待处理队列约每 0.5 秒推进，失败或无进展时约 3 秒重试；安全条件不满足时会延后，因此不是即时关闭。按区域边界距离选取，不是全地图清除死亡机制，也不关闭所有坠落伤害、KillZ 或其他伤害来源。
请在正常地面站稳，并与即死区域边界保持约 3 米以上距离再切换。移动、浮空或距区域过近时，操作可能被拒绝或延后。离开 30 米范围不会自动恢复已禁用的区域；再次按 F7 请求恢复，必要时回安全地面站稳等待。

【为何初版取消横跑】
测试中，适合稳定横向跑墙的长直墙和场地较少，且出现了横跑退出后浮空／飞天的 bug。为缩小初版范围，横向跑墙暂时关闭；文件中保留的横跑依赖不代表功能开放。空中抓锁链互动也暂未开放。

【安装与改键】
1. 完全退出游戏并备份存档。单独安装适配当前游戏版本的 UE4SS，本包不含 UE4SS、DLL 或游戏动画资产。
   前置参考：https://www.nexusmods.com/phantombladezero/mods/13
2. 将本包 Mods 文件夹合并到游戏的 platform\steam\ue4ss 文件夹。示例最终路径：
   platform\steam\ue4ss\Mods\PBZFreeParkour\Scripts\main.lua
   platform\steam\ue4ss\Mods\PBZNearbyKillToggle\Scripts\main.lua
   platform\steam\ue4ss\Mods\PBZNoSplineWall\Scripts\main.lua
   每个模块已含 enabled.txt，不要覆盖自己的 mods.txt，不要多套一层 Mods。三个模块可以分别安装。
3. 停用旧开发模块或同功能副本，尤其 PBZParkourZipTest、PBZKillZipTest 等。已安装独立 PBZNoSplineWall 时，备份后替换同名模块，不要同时启用第二份。检查已有 mods.txt 是否将同名模块设为禁用。
4. 用记事本打开对应模块的 Scripts\keybindings.lua，例如改为：
   return { toggle = 'F10' }
   F7/F6 共用 PBZNearbyKillToggle/Scripts/keybindings.lua：return { toggle = 'F7', display = 'F6' }。支持 F1～F12 单键，四个功能选不同键并避开其他模组。保存后完整重启游戏。配置错误会回退默认键并记录原因。自定义跳跃键、手柄及组合键未适配，跳跃请保持空格。
5. 没有完整画面内状态面板。UE4SS.log 前缀分别为 [PBZ-PARKOUR]、[PBZ-KILL-NEAR]、[NOSPLINEWALL]。开关冲突或碰撞被其他模组修改可能影响效果。
6. 卸载前回安全区域，关闭跑酷并等动作结束，在正常地面恢复 F7/F9 修改后退出游戏，移走不需要的模块。若恢复状态不明确，正常退出并重新启动游戏，再从安全存档进入。
